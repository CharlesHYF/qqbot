压力测试说明。创建于 2026-07-29，修改于 2026-11-23。

压测：不适用

理由：
- 唯一对外接口 `POST /webhook` 只接收 QQ 开放平台推送的群 @ 消息，请求量由群成员手动 @机器人决定，峰值远低于 Workers 免费版每天 10 万次请求的上限。
- 接口同步部分只做 Ed25519 验签和返回 ACK，耗时由 Workers 平台保证；回答在 `ctx.waitUntil` 中异步执行，吞吐上限由智谱免费模型并发和 QQ 被动回复次数决定，不由本服务决定。
- 压测需要合法签名，并且会消耗模型免费额度、向真实群发消息，不适合在 dev/test 环境以外执行。

上线后如群规模扩大，再按 skill 的压测规范补 k6 脚本与报告。
